# Salon Appointment Scheduler

This project is part of freeCodeCamp's Relational Database Certification. It features a PostgreSQL relational database to manage customers, services, and appointments, along with an interactive Bash script (`salon.sh`) to handle user input and database operations.

## Project Structure
- `salon.sql`: The complete PostgreSQL database dump.
- `salon.sh`: An interactive Bash script that interacts with the user and the database to book salon appointments.
